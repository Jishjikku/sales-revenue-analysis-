# Sales & Revenue Analysis Dashboard

An internship project that analyzes sales and revenue data and presents business insights through an interactive Streamlit dashboard.

## Key Features

- Import and analyze CSV sales data
- Total sales, total profit, units sold, and average order value KPIs
- Monthly sales/revenue trend
- Top-performing product analysis
- Region and category analysis
- Interactive filters for region, category, and product
- Data tables for detailed analysis

## Technologies

- Python
- Pandas
- Matplotlib
- Plotly
- Streamlit

## Project Files

- `dashboard.py` - interactive dashboard
- `sales.py` - command-line analysis and chart
- `sales_data.csv` - sample sales dataset
- `requirements.txt` - Python dependencies

## Installation

```bash
pip install -r requirements.txt
```

## Run the dashboard

```bash
streamlit run dashboard.py
```

## Run the analysis script

```bash
python sales.py
```
